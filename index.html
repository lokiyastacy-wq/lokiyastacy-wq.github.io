Radar - Política de privacidad

Radar es una herramienta personal de análisis de mis propios canales de YouTube. Solo yo la uso.

Qué datos usa

Con mi permiso de solo lectura, lee datos de mis propios canales (vistas, suscriptores, retención, tráfico y, si están disponibles, CTR e impresiones) mediante las API de YouTube Data, YouTube Analytics y YouTube Reporting.

Dónde se guardan

Los datos y el permiso se guardan únicamente en mi propio ordenador. No se comparten, no se venden ni se transfieren a terceros.

Cómo retirar el permiso

Se puede retirar en cualquier momento en myaccount.google.com/permissions.

El uso y la transferencia de la información recibida de las API de Google cumplen la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.
